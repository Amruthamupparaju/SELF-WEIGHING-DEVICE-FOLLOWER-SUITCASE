# SELF-WEIGHING-DEVICE-FOLLOWER-SUITCASE
Suitcase will follow the user by making using of Bluetooth HC-05 module which acts as an interface between users mobile phone (app) and the microcontroller inside the suitcase  Will make use of authorization (password) in order to connect to the suitcase for security which will be facilitated using the app
